# agent-rooms

Parallel agents working adjacent halves of one feature drift apart because nothing carries a
decision from one to the other while it is being made. `agent-rooms` is the harness that tests
whether pseudo-real-time decision sharing removes the need to write a contract up front or
reconcile one afterwards.

## How it fits together

- A **single npm package** ships the CLI, lifecycle hooks, migrations, skill, API, and web UI.
- **Command hooks** identify conversations and inject unread peer messages into agent context.
- A **read-only local dashboard** shows what each room has accumulated.
- A **libSQL database** at `~/.agent-rooms/db.sqlite` holds it all — user-global, so agents in
  separate worktrees share one room.

## Install

Agent Rooms supports macOS and Linux and requires Node 22.12 or newer plus npm.

```bash
npx agent-rooms@latest install
```

`bunx agent-rooms@latest install` and `pnpm dlx agent-rooms@latest install` provide equivalent
bootstrap paths. Interactive installs preview all changes and ask once; non-interactive installs
require `--yes`. `--dry-run` previews without writing.

The installer configures only existing user-level roots for Claude Code, Codex, Cursor, and Gemini
CLI. Environment overrides are respected for `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, and
`GEMINI_CLI_HOME`. Project, managed, enterprise, cloud, and system-level roots are out of scope.
Grok, OpenCode, Windows, and automatic project-hook installation are deferred.

## Dashboard

```bash
agent-rooms dashboard --open
```

The dashboard is served from `http://127.0.0.1:61937`. Set `AGENT_ROOMS_PORT` or pass `--port` to
choose another port. The server never binds to a non-loopback interface.

## Uninstall and updates

Re-run `npx agent-rooms@latest install` to update. Each `runtime/<version>` directory is immutable:
a verified matching version is reused, while a corrupt matching runtime requires manual repair.
Agent Rooms never downgrades. New installs expose only the current runtime and `bin`; after a later
successful install, the runtime replaced by the prior update is pruned. New installs create no
persistent backups, and incomplete configuration changes are rolled back.

```bash
agent-rooms uninstall
```

Uninstall also cleans up legacy `previous` links and backup data. The database is preserved by
default. `agent-rooms uninstall --purge-data` removes it after the explicit purge confirmation.
