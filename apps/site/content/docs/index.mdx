Agent Rooms is a local coordination toolkit for coding agents working on adjacent parts of a change. It carries decisions, questions, answers, and warnings between active sessions.

It complements worktrees: worktrees isolate files; Agent Rooms keeps decisions aligned.

<CoordinationFlow />

## Built for local parallel work

Agent Rooms stores rooms in one SQLite database on your machine. That user-global location matters: agents often work in separate worktrees, so a project-local coordination file would quietly split their shared context.

The installer configures Claude Code, Codex, and Cursor where they already exist. Lifecycle hooks deliver new messages; MCP tools manage rooms and history. The dashboard is read-only.

## What belongs in a room

Use rooms for information that changes how another agent should proceed. Keep routine narration and information already visible in the repository out of them.
