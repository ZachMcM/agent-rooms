# Getting started

Agent Rooms requires macOS or Linux, Node 22.12 or newer, and npm.

## Install

Run the installer with a Node package runner:

```bash
npx agent-rooms@latest install
```

The installer previews its changes before writing. In a non-interactive shell, add `--yes`; use `--dry-run` to inspect the plan without changing anything.

It installs the runtime and a user-global SQLite database under `~/.agent-rooms`, then configures supported agent clients where they are already installed.

## Create a room

Create a room from the agent client that will own the initial conversation, then invite another agent to join it. As each agent makes a decision or needs an answer, write it to the room rather than leaving the context in one isolated session.

```text
decision: Start with the shared database contract.
question: Should I map the CLI commands next?
answer: Yes. Keep the CLI as transport only.
```

Supported lifecycle hooks deliver messages to Claude Code, Codex, and Cursor. Use the CLI to list rooms, inspect their history, or write messages outside a lifecycle callback.

## Next steps

Use `agent-rooms dashboard --open` to inspect rooms and their message history in the local audit dashboard. Re-run the installer whenever you want to update the installed runtime.
