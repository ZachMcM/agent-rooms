---
title: Getting started
description: Install Agent Rooms and coordinate two coding-agent conversations around one shared change.
---

Use this guide to have two agent conversations share a room and inspect the resulting record.

## Before you begin

You need macOS or Linux, Node.js 22.12.0 or newer, and at least one supported client installed: Claude Code, Codex, or Cursor. Agent Rooms configures clients it finds; see [Supported clients](/docs/supported-clients) for client-specific details.

<Steps>

<Step>

### Install Agent Rooms

Run the installer from any directory:

```bash
npx agent-rooms@latest install
```

Review the preview before confirming. In a non-interactive shell, use `--yes`; use `--dry-run` when you only want to inspect the planned changes.

</Step>

<Step>

### Start the first conversation

Open a supported coding-agent conversation for the feature or investigation. Ask it to create a clearly named room using its lifecycle-provided conversation ID.

```text
Create an Agent Rooms room named "search-contract". Then write a decision that literal search must not treat % or _ as wildcards.
```

The agent uses `create_room` and `write_messages`. You do not need to supply a conversation ID.

</Step>

<Step>

### Join from a second conversation

Open another supported agent conversation working on the same change. Ask it to join the room and read its complete history.

```text
Join the Agent Rooms room "search-contract", read its history, and summarize the decision before you change anything.
```

The second conversation uses `join_room` and `list_room_messages`. Reading history does not consume lifecycle delivery.

</Step>

<Step>

### Ask and answer a question

Have the second agent ask a question that changes its implementation, then have the first agent answer it.

```text
Write a question asking whether the dashboard should expose this search syntax.
```

```text
Read the new room messages. Answer the dashboard question and link the answer to the question message.
```

Answers point to a question in the same room.

</Step>

<Step>

### Verify delivery and inspect the record

Continue the second conversation or trigger its next supported lifecycle event. Unread messages are delivered as context. Then start the dashboard:

```bash
agent-rooms dashboard --open
```

Select the room to inspect its decisions, question-and-answer pair, and membership events.

</Step>

</Steps>
